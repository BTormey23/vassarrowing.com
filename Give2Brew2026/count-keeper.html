GitHub access token

Saved only in this browser.

Set up (once)

  1. Drag this button to your bookmarks bar:
    ONE OF 1000 Count Keeper
  2. Paste the GitHub token Brian gives you in the box above and click Save token, then Check token.

On giving day

  1. Open Rowing's GiveCampus team page (the page that shows Rowing's donors and dollars) in this same browser.
  2. Click the Count Keeper bookmark. This window opens; leave both open.
  3. A small burgundy box in the corner of the GiveCampus tab shows each reading. This window shows each update to the site.
  4. Keep the computer awake and plugged in (on a Mac: System Settings → Battery/Lock Screen, or run caffeinate -d in Terminal). If either window closes, reopen the team page and click the bookmark again.

Test it any time on last year's Rowing page. Readings from 2025 are marked as a test and never show on the campaign page.
